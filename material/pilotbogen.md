## Beobachtung

Markiere nur, was für die Überarbeitung des Materials wichtig ist.

### Auftrag
- [ ] Kind versteht den Auftrag ohne zusätzliche Erklärung.
- [ ] Eine kurze Erklärung reicht.
- [ ] Auftrag ist noch zu kompliziert.

Notiz:

### Lesebelastung
- [ ] Umfang wirkt passend.
- [ ] Zu viel Text.
- [ ] Zu viele Aufgaben.
- [ ] Schrift / Zeilenabstand erschweren das Lesen.

Notiz:

### Zielreinheit
- [ ] Aufgabe trainiert sichtbar die geplante Teilkompetenz.
- [ ] Eine andere Schwierigkeit überlagert das Lernziel.

Welche?

### Selbstständigkeit
- [ ] Material kann selbstständig genutzt werden.
- [ ] Selbstkontrolle funktioniert.
- [ ] Lösung / Kontrolle ist unklar.
- [ ] Kind benötigt wiederholt Hilfe bei der Bedienung.

Notiz:

### Motivation und Arbeitsweise
- [ ] Kind bleibt bei der Aufgabe.
- [ ] Format wird schnell verstanden.
- [ ] Wiederholung desselben Formats erscheint sinnvoll.
- [ ] Gestaltung lenkt von der Aufgabe ab.

Notiz:

## Mini-Rückmeldung des Kindes

Optional, mündlich:

- Was war sofort klar?
- Was war schwierig?
- Würdest du so eine Aufgabe noch einmal machen?

## Entscheidung

- [ ] unverändert als Serienvorlage geeignet
- [ ] kleine Überarbeitung
- [ ] deutliche Überarbeitung
- [ ] Format nicht weiterverwenden
